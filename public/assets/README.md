# public/assets
Copy to your Next.js project: `public/assets`. Use paths like `/assets/logo/logo.svg`.
- logo/: logo + logo-dark (wordmark falls back to Georgia if Playfair Display is not loaded), logo-mark(+dark) without text
- favicon.svg, apple-touch-icon.svg: app icons
- categories/: 6 category cards (600x400); icons/: category icons + "Why choose" icons
- images/: hero (+dark), auth-side, 404, og-image (export to PNG 1200x630 for social sharing)
- placeholders/: service-1..6 and avatar for empty data
All are original SVG illustrations. Replace with real photos before launch.
